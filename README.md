# Komentář k zákonu č. 191/1950 Sb., zákonu směnečnému a šekovému

Otevřený komentář k zákonu směnečnému a šekovému — ustanovení po ustanovení (čl. I zákon směnečný, čl. II zákon šekový, čl. III úvodní a závěrečná ustanovení): doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; náležitosti směnky, indosament, přijetí, aval, splatnost a placení, postih, protest, promlčení, vlastní směnka a šek.

Konsolidované znění: dokument e-Sbírky `SB-1950-00191_2014-01-01`.
